# Сайт ППО Ремонтного управління

Статичний сайт для GitHub Pages.

- `index.html` — публічна головна: новини, профком, статистика, документи, «Як вступити». Дані беруться з Apps Script (`?api=home`), лише загальна інформація без персональних даних.
- `profkom.html` — облік членів профкому (вбудовано з Apps Script, вхід за кодом на email).
- `oblik.html` — облік членів профспілки (вбудовано з Apps Script, вхід за кодом на email).
- `config.js` — адреса веб-застосунку Apps Script. Змініть її, якщо створите нове розгортання.

## Публікація
Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save.
Через 1–2 хвилини сайт буде за адресою `https://<користувач>.github.io/<репозиторій>/`.

Персональні дані членів на GitHub **не зберігаються** — вони лишаються в Google Таблиці й доступні лише після входу.
